# Prompt — Pesquisa que vira sistema de decisão

**Quando usar:** em vez de "pesquise X" (devolve texto), pedir pesquisa + critérios + pesos + interface. Une Deep Research, vibe coding e agentes numa disciplina só.

**IC-RAV:** Intenção (decisão a tomar) · Contexto (assunto) · Resultado (dashboard com critérios ajustáveis) · Autonomia (IA define critérios e pesos) · Verificação (fontes visíveis).

```text
Pesquise:

[ASSUNTO]

Mas não quero apenas um relatório.

Quero utilizar a pesquisa para tomar esta decisão:

[DECISÃO]

Determine os critérios relevantes.

Pesquise informações atualizadas.

Mostre as fontes.

Estruture os dados.

Crie pesos para os critérios quando fizer sentido.

Compare as alternativas.

E construa uma interface ou dashboard que permita alterar
os critérios e visualizar como a decisão muda.
```
